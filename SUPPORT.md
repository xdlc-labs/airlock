# Support

Airlock is a volunteer-maintained **public beta**. Expect rough edges. APIs and discovery coverage may change before 1.0. Current release: [CHANGELOG](CHANGELOG.md) / [Releases](https://github.com/xdlc-labs/airlock/releases).

| Need | Where |
|------|--------|
| Bug / feature | [GitHub Issues](https://github.com/xdlc-labs/airlock/issues). Include `airlock version`, OS, and a minimal repro |
| How-to / design | [Discussions](https://github.com/xdlc-labs/airlock/discussions) or an issue labeled `question` |
| Roadmap | [Developer guide](https://xdlc.dev/airlock/docs/guide) and [roadmap](https://xdlc.dev/airlock/docs/roadmap) |
| Security | [SECURITY.md](SECURITY.md) only |
| Contributing | [CONTRIBUTING.md](CONTRIBUTING.md) |
| Release notes | [CHANGELOG.md](CHANGELOG.md) |

There is **no SLA** and no commercial support contract for the OSS CLI.
